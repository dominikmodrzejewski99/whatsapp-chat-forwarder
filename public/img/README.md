# Ikony aplikacji

W tym katalogu powinny znajdować się następujące pliki ikon:

- `favicon.ico` - Podstawowa ikona strony (16x16, 32x32)
- `favicon-16x16.png` - Ikona 16x16 px
- `favicon-32x32.png` - Ikona 32x32 px
- `apple-touch-icon.png` - Ikona dla urządzeń Apple (180x180 px)
- `android-chrome-192x192.png` - Ikona dla urządzeń Android (192x192 px)
- `android-chrome-512x512.png` - Ikona dla urządzeń Android (512x512 px)
- `og-image.jpg` - Obraz dla Open Graph (Facebook) (1200x630 px)
- `twitter-image.jpg` - Obraz dla Twitter Cards (1200x600 px)

## Jak wygenerować ikony

Możesz użyć narzędzi online takich jak:
- [Favicon Generator](https://realfavicongenerator.net/)
- [Favicon.io](https://favicon.io/)

Aby wygenerować kompletny zestaw ikon na podstawie jednego obrazu.

## Kolory

Główny kolor aplikacji: `#128C7E` (WhatsApp Green)
